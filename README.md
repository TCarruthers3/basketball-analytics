# 🏀 Basketball Analytics

Exploring NBA player and team performance using Python, pandas, and the NBA API.
This is my first test at using python, github, VScode and Claude to do data analysis

## Projects

### 1. Top 20 Scorers – 2024-25 NBA Season
Pulls live player stats from the NBA API and identifies the top 20 points-per-game leaders for the 2024-25 season.

**Key findings:**
- Shai Gilgeous-Alexander led the league at 32.7 PPG
- Analysis filters to players with 60+ games played for statistical reliability
- Visualised as a horizontal bar chart

**Tools used:** Python, pandas, nba_api, matplotlib

## Setup

1. Clone this repo
2. Install dependencies:
   pip install nba_api pandas matplotlib
3. Run the analysis:
   python analysis.py
